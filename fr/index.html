Application Android

CaCam

Une application Android signée qui envoie directement la caméra du téléphone vers l’ordinateur. Son code source est privé ; les versions publiques de l’application sont proposées ici.

  • Mode USB BGOBS limité au câble et sélectionné par défaut
  • Transports ADB, MJPEG/HTTP et RTSP/H.264
  • Sans compte, analyse d’usage, publicité ni serveur CaCam distant

Extension tierce pour OBS Studio

BGOBS Beau Gosse

Une extension open source pour supprimer ou flouter l’arrière-plan, améliorer les contours et la basse lumière, et recevoir directement la vidéo USB ou ADB de CaCam.

  • Suppression et flou d’arrière-plan
  • Amélioration des contours et de la basse lumière
  • Sources USB et ADB CaCam directes et facultatives

CaCam capture. BGOBS reçoit.

Utilise CaCam seul sur Android avec des protocoles locaux standards, ou associe-le à l’extension open source BGOBS pour une liaison USB directe dans OBS Studio. La vidéo reste entre tes appareils.
