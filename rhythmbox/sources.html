Édition LeMegaGeek 0.9.0, code 18

Nom affiché dans le lanceur Android : Rhythmbox LeMegaGeek. Identifiant Android : fr.lemegageek.rhythmbox. Cette édition s’installe séparément de l’ancienne application ; elle ne lit pas automatiquement ses comptes, autorisations ou données privées.

Elle conserve le lecteur local, les listes pCloud, le cache privé, les copies audio choisies, le contrôle Spotify App Remote et les catalogues Suno à partir de liens partagés. L’analyseur natif inclut le correctif des bandes de basses fréquences. Le nouveau parcours Suno ouvre la connexion officielle dans un onglet du navigateur, avec Google ou la méthode habituelle du compte. Depuis la bibliothèque ou les playlists affichées dans le navigateur, l’action « Écouter dans Rhythmbox » transmet la page choisie à l’application ; une confirmation précède l’import et la lecture natives. Les cookies et identifiants restent dans le navigateur. Les sélections doivent être partageables : le client ne synchronise pas automatiquement toute la bibliothèque privée ou les favoris privés Suno.
